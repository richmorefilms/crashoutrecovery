            Help / Ops Manual

            Full operations guide — modes, options, how-to, tiers, alerts, and console testing. Adults 18+. No real billing.

            What this app does

            Crashout Recovery helps you pause before posting something you might regret. You type your thought, the app reads the vibe, suggests a calmer draft, and lets you save it as a {{ uc.seed.label | lower }} instead of blasting it out. It’s about building habits, not therapy or payments.

            Hot thought → vibe check → {{ uc.momentum_cta.label | lower }} → optional safe move → save {{ uc.seed.label | lower }} → {{ uc.recovery_streak.label | lower }} grows

            Accounts, privacy, and sync

            • Guest: recovery history, draft ideas, and signals stay in this browser's local cache.
            • Account: those four caches and the selected preview tier sync to this app's SQLite database. Registration uploads current guest data; signing into an existing account pulls its saved data.
            • Tone requests: full suggestions send the entered text to this app's server. The server records pattern previews and may retain successful inputs in its local training-review log; a browser-only fallback runs if the request fails.
            • Logout: ends the account session but leaves browser-cached drafts and activity in place. Clear the browser demo cache after logout on a shared device.

            Quick map

            • Drama — examples of meltdowns, with suggestions for calmer moves
            • Moments — a shared YouTube clip catalog; Creator+ can add or update IDs
            • Headlines — what’s trending or “spicy” online
            • Signals — today’s world mood; {{ uc.signals_pro.label | lower }} unlocks forecasts
            • Posts — saved {{ uc.seed.label | lower }}s + weekly {{ uc.recovery_streak.label | lower }}
            • Creator — {{ uc.recovery_streak.label | lower }}s, {{ uc.seed.label | lower }}s, safe moves, {{ uc.momentum_score.label | lower }}

            Everyday recipes

            • About to post something risky — Draft → Read vibe → Take safe move → Save {{ uc.seed.label | lower }} → Done
            • Feed feels spicy — Tap flashing chip → Signals → Save {{ uc.seed.label | lower }} instead of posting
            • Want better wording — Draft → choose a database-guided rewrite → edit before saving
            • Check habits — Creator → {{ uc.momentum_score.label | lower }} + {{ uc.recovery_streak.label | lower }}

            How lanes work

            The tab bar switches one panel at a time. {{ uc.pulse_strip.label }} stays visible on every lane. Special panels include {{ uc.signals_pro.label | lower }} and the Creator dashboard. Feed cards appear for Drama, Moments, Headlines, and Posts.

            Mode A — Drama

            Learn from others' mistakes: meltdowns, beefs, algorithm dips, impulsive decisions, turnarounds. Each card has a micro-action that opens the draft box with a hint in the placeholder.

            • When to use: you feel heated and need perspective before posting
            • Primary action: tap card action → Draft
            • Tone sort: after a tone read, Drama re-sorts toward matching tone

            Mode B — Moments

            Moments loads the shared clip catalog from /videos.json. Tap a thumbnail to open a privacy-enhanced YouTube player. Clips without a resolved ID use a YouTube search fallback.

            • When to use: you want a fast visual / narrative spike example
            • Primary action: tap Play or Search on a clip thumbnail
            • Add Video (Creator+): enter a search query and, optionally, an 11-character YouTube ID or supported YouTube URL
            • Query-only lookup: requires CRASHOUT_YOUTUBE_API_KEY on the server unless that query is already cached
            • Shared catalog: Add Video and Set ID write to the server-wide videos.json file, refresh the grid, and affect every user; there is currently no delete control

            Mode C — Headlines

            Pop-culture and platform context: drama summaries, creator news, meltdown moments, algorithm dips. Good for “is this just me, or is the feed spicy today?”

            Mode D — Signals

            {{ uc.signals_pro.label }} home. Replaces the normal feed list on this tab.

            • Everyone: Today's signals (chips, categories, headlines)
            • Pro: 72h forecast, burnout clusters, algorithm dip recovery tip
            • Basic/Plus/Creator: locked Pro block + Unlock Pro button
            • Entry: tab or any pulse chip from the {{ uc.pulse_strip.label | lower }}

            Mode E — Posts

            Your circle: draft ideas, threads, replies, micro-threads. Also hosts:

            • Your Week — {{ uc.recovery_streak.label | lower }} card (spike history + tone trend slots)
            • {{ uc.bad_decision_predictor.label }} summary — after a {{ uc.composer.label | lower }} analysis (Creator-gated depth)
            • Personal stages — tone card + deeper crashout tools after Draft

            Mode F — Creator

            Ops dashboard. {{ uc.momentum_score.label }} sits above the locked body (always visible). Below: {{ uc.recovery_streak.label | lower }}, tone dots, spike bars, saved {{ uc.seed.label | lower }}s, last safe move. Unlock Creator Mode to undim and read clearly.

            {{ uc.pulse_strip.label }} (every mode)

            • A Tap any chip → switch to Signals + highlight matching row
            • B Tap high chip → same + {{ uc.global_spike_alert.label | lower }} row flash (1.5s)
            • C Bar/chips auto-flash when any today signal is high
            • D Unlock lock chip (if shown) → upgrade toward Pro
            • Pro bonus: jump can also flash related forecast rows

            Flash is visual only — not paid. Basic users still get flash + lane jump.

            Why the {{ uc.composer.label | lower }} exists

            The {{ uc.composer.label | lower }} is the recovery workbench. You enter the hot thought, get a tone read, receive one {{ uc.momentum_cta.label | lower }} (a {{ uc.seed.label | lower }}), then optionally a {{ uc.bad_decision_predictor.label }} for safer next steps. A completed tone read switches the underlying feed to Posts; Done closes the draft box and leaves Posts active.

            How-to — full {{ uc.composer.label | lower }} loop

            1. Tap the floating + Draft button (any lane).
            2. Type (or paste) the raw spike — e.g. “I'm deleting everything and quitting forever…”
            3. While typing, watch the live local tone preview on the {{ uc.tone_pills.label | lower }}.
            4. After about 850 ms without typing, the full server suggestion runs automatically. Tap Read tone & suggest a move or press Ctrl/Cmd+Enter to run it immediately.
            5. {{ uc.tone_pills.label }} appear with a short reason. Tap a button to override tone manually.
            6. {{ uc.momentum_cta.label }} card appears: hook, micro-action, editable draft preview.
            7. If Creator+: {{ uc.bad_decision_predictor.label }} shows spike level, risk vs safe move, reason.
            8. Optional: Take safe move (writes into draft preview + {{ uc.recovery_streak.label | lower }}) or Copy safe move.
            9. Optional: Save {{ uc.seed.label | lower }} — updates the browser cache, bumps {{ uc.recovery_streak.label | lower }}, updates {{ uc.momentum_score.label | lower }}, and syncs when logged in.
            10. Choose a curated or clearly labeled AI-assisted rewrite, then edit it before saving.
            11. Tap Done to close; Posts remains active so you can see Your Week.

            Spike text → Tone read → {{ uc.momentum_cta.label }} ({{ uc.seed.label | lower }}) → {{ uc.bad_decision_predictor.label }}

            Tone system (options)

            • humorous — spark / meme-level energy
            • direct — blunt signal; often higher spike risk
            • strategic — draft idea / one-variable thinking
            • calm — draft / soft rewrite
            • universal — default steady draft idea

            Team model / topic blocks apply on /api/suggest. The request sends the entered text to this app's server; local decision-flow can fill in when the network fails.

            Action options after tone read

            • Turn this into a post — expand post framing on the draft idea
            • Start a thread — swaps draft to a thread-starter line
            • Save draft idea — persists to crashout_seeds, streak win, progress meter refresh
            • See drama lane — jump Drama for similar examples
            • Watch moments — jump Moments for clip-style examples
            • Rewrite choices — calm, clear, and stable options drawn from reviewed content first
            • Recovery actions — contextual safe moves shown directly in the draft box

            {{ uc.bad_decision_predictor.label }} options (Creator+)

            • Basic: locked / teaser + Unlock Creator Mode
            • Creator+: spike label, risk language, safe move, reason
            • Take safe move: apply text to draft preview + record win + lastSafeMove
            • Copy safe move: clipboard
            • Posts lane: summary card after analysis

            {{ uc.recovery_streak.label }} — what it tracks

            Streaks reward reversible habits, not posting hot takes. Wins come from saving {{ uc.seed.label | lower }}s and taking safe moves. Data lives in crashout_recovery.

            • streak — consecutive days with a win
            • history — last ~7 spike levels (low / steady / rising / hot)
            • tones — last ~7 tone reads
            • wins — total wins
            • lastSafeMove / lastSafeAt — last applied risk-check safe move

            Where to see it

            • Posts → Your Week — streak count, spike graph, tone trend slot, upgrade slot
            • Creator dashboard — denser streak + draft ideas + last safe move
            • Toasts — “Draft saved” / “Safe move taken” confirmations

            How wins happen

            1. Save draft idea in draft box → win / streak hold or +1 for a new day
            2. Take safe move in risk check → win + lastSafeMove set
            3. Pipeline tone reads can add spike history entries for progress meter scoring

            {{ uc.momentum_score.label }} (Creator tab, always visible)

            Heuristic 0–100. Not gated as a card — even locked dashboards show it. Levels: low (0–39), medium (40–69), high (70–100). {{ uc.momentum_score.tooltip }}

            • Win-streak day: +4 per day (max 40)
            • Safe move taken: +20
            • Draft ideas saved: +2 each (max 20)
            • Spike history: low +2, rising −1, hot −3
            • Add-ons installed: +5 each (max 20)
            • Pro tier + no high world signal today: +10
            • Final score clamped 0–100

            Recommended 10-minute operator tour

            Follow in order the first time. Use Preview buttons if Unlock UI feels slow.

            1. Drama — skim 1–2 cards; tap an action so Draft opens with a prompted placeholder.
            2. Type a realistic crashout thought → wait for automatic analysis or tap Read tone → note tone buttons, suggested next step, draft idea, risk check state.
            3. Preview Creator → Take safe move → Save draft idea → watch toast.
            4. Close Done → open Posts → inspect Your Week (win streak, graph slots).
            5. Draft again → compare calm, clear, and stable rewrites → edit one before saving.
            6. Open Creator → read progress meter number + description; confirm draft idea list.
            7. Open Moments → play a thumbnail; Creator+ can use Add Video with a query and optional YouTube ID.
            8. From any lane, tap a flashing high pulse → land on Signals with row flash.
            9. Preview Pro → expand forecast, burnout clusters, algo tip.
            10. Optional: log out, then use Console → Reset browser demo cache for a guest-only clean pass.

            Everyday how-to recipes

            • I'm about to post something I'll regret

              Draft → Read tone → Take safe move (Creator) → Save draft idea → Done. Do not open the real social apps until the draft idea feels calm.

            • The feed feels spicy today

              Check signal bar flash → Signals. If Pro, read forecast / burnout. Save one draft idea instead of a reply-all essay.

            • I want better wording tools

              Draft → compare database-guided rewrites → edit the clearest option.

            • I want to know if habits are holding

              Creator → progress meter + win streak. Posts → Your Week for weekly framing.

            • I want to add a YouTube clip

              Sign in with a Creator or Pro preview → Moments → Add Video → enter a search query → optionally paste a YouTube ID or URL → Submit. The clip is saved to the shared server catalog.

            • Is: creator recovery UI with server-assisted tone suggestions, account sync, a shared video catalog, and unlock-level scaffolding

            Browser cache & session keys

            The first four keys are offline/browser caches. When logged in, updates sync to structured SQLite records for the account.

            • crashout_recovery — win streak, history, tones, wins, lastSafeMove
            • crashout_seeds — saved draft ideas
            • crashout_world_signals — world trends + today list for alerts
            • crashout_jwt, crashout_refresh, crashout_user — signed-in session and cached account identity

            Reset browser demo cache

            localStorage.removeItem('crashout_recovery')
localStorage.removeItem('crashout_seeds')
localStorage.removeItem('crashout_world_signals')
location.reload()

            Log out first for a guest-only reset. If you remain logged in, account data may sync back after reload. This does not erase account records, session keys, videos.json, the YouTube cache, or server logs.
